# GEMINI AI Integration Setup Guide

## 🚀 GEMINI API Configuration

### Step 1: Get Your GEMINI API Key

1. Visit [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Sign in with your Google account
3. Click "Create API Key"
4. Copy your API key (it starts with `AIza...`)

### Step 2: Configure Environment Variables

Create or update your `.env.local` file in the root directory of your project:

```bash
# GEMINI API Configuration
GEMINI_API_KEY=your_api_key_here
# OR alternatively (both work, but GEMINI_API_KEY is preferred)
NEXT_PUBLIC_GEMINI_API_KEY=your_api_key_here
```

**Important:**
- Replace `your_api_key_here` with your actual GEMINI API key
- Never commit `.env.local` to version control
- Restart your development server after adding the API key

### Step 3: Restart Your Development Server

```bash
npm run dev
# or
yarn dev
```

## 🎯 Features Implemented

### ✅ Real-time Quiz Generation
- **Topic-based quizzes**: Enter any topic (e.g., "Climate Change", "Space Exploration", "Ancient History")

- **AI-powered questions**: Generated by GEMINI AI with educational value
- **Explanations**: Detailed explanations for correct answers

### ✅ Anti-Duplication System
- **Smart caching**: Prevents identical quizzes
- **Content validation**: Ensures unique questions every time
- **Cache management**: LRU eviction to maintain performance

## 🔧 API Endpoint

The quiz generation is available at:
```
POST /api/quiz
```

**Request Body:**
```json
{
  "topic": "Climate Change",
  "difficulty": "medium",
  "questionCount": 5
}
```

**Response:**
```json
{
  "questions": [...],
  "topic": "Climate Change",
  "difficulty": "medium",
  "modelUsed": "gemini-2.5-flash"
}
```

## 🐛 Troubleshooting

### Common Issues

**"GEMINI_API_KEY is not configured"**
- Check your `.env.local` file
- Ensure the API key is correct
- Restart your development server

**"Invalid API key"**
- Verify your API key from Google AI Studio
- Ensure no extra spaces or characters

**"API quota exceeded"**
- Check your GEMINI API usage limits
- Consider upgrading your API plan

**"Failed to generate quiz"**
- Check your internet connection
- Try a different topic
- Check API console for errors

### Debug Mode

For debugging, you can check the API health:
```bash
GET /api/quiz
```

This will return the API status and cache information.
